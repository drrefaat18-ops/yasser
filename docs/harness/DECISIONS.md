## Standing lessons

- **Slash commands are not enforcement boundaries.** A gate that lives only in skill prose can be bypassed by calling the tool directly. Every entry point enforces its own preconditions. (Source: Codex review §2.)
- **A bare `PASS` is not a regression baseline.** Two implementations can both print PASS while one skips every check. Compare structured per-check reports. (Source: Codex review §4.)
- **A documented rule is not an enforced rule.** `verify_refs.py` claims to allow a missing DOI only for laws/guidance, but it accepts every missing DOI (`rework/tools/verify_refs.py:1-6,53-57`). Test the rule, not the docstring.
- **Self-review is labelled as such.** `rework/REVIEW_REPORT.md:8` admits the re-score was a self-assessment. The harness audit stage uses a different model.
